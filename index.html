Ruta de aprendizaje que llevamos

  1. 01. Fundamentos y lógica de programación

    Aprendemos a analizar problemas y plantear soluciones mediante algoritmos, condiciones, ciclos, arreglos y funciones.

    PSeIntAlgoritmosJava

  2. 02. Análisis y diseño de software

    Identificamos necesidades, documentamos requisitos y representamos cómo funcionará una solución antes de desarrollarla.

    RequisitosHistorias de usuarioUMLDraw.io

  3. 03. Construcción de interfaces web

    Organizamos el contenido de una página, damos estilo a sus secciones y añadimos interacciones para mejorar la experiencia de las personas.

    HTMLCSSJavaScriptVisual Studio Code

  4. 04. Bases de datos y programación del servidor

    Diseñamos modelos entidad-relación, practicamos consultas SQL y estudiamos cómo una aplicación procesa y organiza información.

    PostgreSQLMySQLpgAdminPHP

  5. 05. Trabajo colaborativo y control de versiones

    Distribuimos tareas mediante issues, trabajamos en ramas y proponemos cambios con pull requests para construir un proyecto en equipo.

    GitGitHubIssuesPull requests

  6. 06. Próximos pasos

    Queremos integrar lo aprendido en proyectos más completos, reforzar las pruebas, mejorar la seguridad y documentar nuestras soluciones.

  • Análisis y documentación: organización de requisitos, historias de usuario y diagramas para explicar los proyectos.
  • Bases de datos: modelado de información y elaboración de consultas SQL.
  • Lógica de programación: resolución de ejercicios con estructuras de control, arreglos y funciones.
  • Arquitectura y seguridad: interés en la organización de los componentes, los roles y el acceso a la información.

Mi siguiente meta: fortalecer mis habilidades de desarrollo y colaboración para aportar a aplicaciones completas, claras y fáciles de utilizar.
