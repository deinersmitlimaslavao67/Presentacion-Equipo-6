- ## 🚀 Lo que más me gustó del curso de Git y GitHub de Microsoft

Lo que más disfruté de este curso fue su enfoque práctico para entender el control de versiones no solo como un respaldo de código, sino como la base del **trabajo colaborativo profesional**.

### ✨ Puntos que más destaco:
* **Flujo de trabajo con ramas (`branching`):** Aprender a aislar el desarrollo de nuevas funcionalidades sin afectar la estabilidad de la rama `main`.
* **Revisión de código (*Pull Requests*):** Entender cómo auditar, discutir y validar cambios en equipo antes de hacer un `merge`, asegurando la calidad del software.
* **Resolución de conflictos:** Perder el miedo a los *merge conflicts* y comprender cómo solucionarlos de forma ordenada y segura.
* **Organización y buenas prácticas:** El uso de *Issues* para el seguimiento de tareas y la configuración del archivo `.gitignore` para mantener el repositorio limpio y seguro desde el primer `commit`.

> 💡 **En resumen:** El curso me brindó bases sólidas para gestionar repositorios con orden, seguridad y un estándar real de la industria.
